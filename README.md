# ai-passport-anki

FoloToy AI Passport 离线文字闪卡复习器，参考 AnkiDroid 的复习流程和 [消消乐固件](https://github.com/yangguo/ai-passport-xiaoxiaole) 的 BSP。

首版范围已确认：离线文字卡片、间隔复习、电脑 USB 导入牌组。

详细开发设计：[docs/design.md](docs/design.md)。实现计划：[docs/plans/2026-10-11-anki.md](docs/plans/2026-10-11-anki.md)。

状态：设计基线完成，业务实现进行中。使用 Luna high 编码；真机验收 NOT RUN。独立功能移植，不是完整 Anki/FSRS/AnkiWeb 兼容实现。

# AI Passport Anki Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Offline text flashcards, four ratings, persisted review progress, and desktop deck import on FoloToy AI Passport.

**Architecture:** Independent bounded C11 collection and scheduler; ESP-IDF adapter owns input events, LVGL, NVS and USB text protocol. Import validates into a staging collection and persists before activating it. A desktop Python tool converts UTF-8 TSV/legacy APKG to the bounded format and uploads via USB.

**Tech Stack:** ESP-IDF 5.5.3, LVGL 9.5, FoloToy BSP (xiaoxiaole implementation snapshot), C11, Python 3.

### Task 1: collection and scheduler
Files: components/passport_anki/include/passport_anki.h, components/passport_anki/passport_anki.c, tests/test_core.c.
Write failing tests for flip-before-grade, Again relearning, four ordered intervals, due-card selection, time overflow, multiple decks, and capacity. Run CMake/CTest, implement only the tested behaviors, rerun with ASan/UBSan.

### Task 2: portable snapshot and transactional import
Files: components/passport_anki/codec.c, tests/test_codec.c.
Test round-trip, checksum damage, truncated or oversized input, duplicate IDs and invalid UTF-8. Implement fixed endian versioned codec; decoding never changes live state on failure.

### Task 3: desktop import
Files: tools/deck.py, tests/test_deck.py, decks/demo.tsv.
Test TSV/Anki text export and legacy APKG conversion, byte limits, duplicate IDs and error reporting. Generate serial upload commands and subset-font character list. Upload requires device COMMIT acknowledgment; warn that importing replaces collection and review history.

### Task 4: firmware adapter
Files: main/app_main.c, main/idf_component.yml, main/CMakeLists.txt, sdkconfig.defaults, partitions.csv.
Reuse licensed BSP. Implement queue-only callbacks, deck menu, front/back pagination, rating selection, logical-day advance, NVS commit-before-visible-grade, bounded serial import and explicit errors. Never erase NVS on init error. Compile firmware locally if toolchain available; otherwise remote CI must provide build evidence.

### Task 5: docs, automation and publication
Files: README.md, docs/design.md, docs/acceptance.md, docs/sources.md, .github/workflows/ci.yml.
Document all unsupported Anki features and manual clock behavior. Run host tests/import tests/firmware build, publish public yangguo/ai-passport-anki, inspect remote CI. Hardware acceptance remains NOT RUN until actual device testing.
